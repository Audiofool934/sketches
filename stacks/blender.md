# blender

Stack name in `brief.md`: `blender`.

Blender, driven by Python.
Use it for path-traced materials, cloth, or a shot you would light like a film.

Do not install it for a loop.
Leave behind the browser for the render itself.
A preview still frame can be opened anywhere.
The shot does not need `window.seek(t)`.

Every frame is still a pure function of the frame number.
Seeded noise only.
A loop's first frame matches its last, including motion blur.
Name the frame size, the frame count, and the camera in `brief.md` before the first render.
