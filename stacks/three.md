# three

Stack name in `brief.md`: `three`.

Three.js, in the same HTML page if it fits.
This is the 3D renderer for a sketch, because the piece still opens in a browser.

Use it when the camera has to travel through a volume, an object has to turn in light, or the depth of a mechanism is the point.
Fake that depth with scale, parallax, and overlap on `canvas` when a drawing can tell the same idea.

The render contract in `CLAUDE.md` applies.
`window.seek(t)` still draws the frame.
Leave behind Blender.
Do not install Blender for a loop.
