# canvas

Stack name in `brief.md`: `canvas`.

One `index.html`.
Canvas 2D or inline SVG.
No libraries.

SVG fits a short vector loop with a few shapes.
Canvas 2D fits many marks, brushes, particles, type, and anything that must be a pure function of time.

A hand-drawn or textured film stays on Canvas 2D.
One HTML file, until a helper file earns its place.
Leave behind a 3D renderer and an image model.

If the brief names a drawn look, read that one kit in `kits.md`.
Do not add a pack to a plain motion loop.

The render contract in `CLAUDE.md` applies.
Leave behind Remotion, HyperFrames, Three.js, and Blender.
